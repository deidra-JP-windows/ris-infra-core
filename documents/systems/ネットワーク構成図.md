```mermaid
flowchart LR
  subgraph clients["クライアント"]
    Clients[外部ユーザ<br/>コミュニティユーザ<br/>スマホアプリ]
    Member[コミュニティユーザ]
  end
  
  subgraph aws["AWSクラウド"]
    WAF[WAF]:::edge
    CF[CloudFront]
    ACM[ACM（AWS Certificate Manager）]
    AuthLambda[トークン認証Lambda]
    S3_Info[フロントinfo用S3]
    S3_Front[フロントweb用S3]
    API[バックエンドLambda（API Gateway/Lambda）]
    S3_Backend[バックエンド用S3]
    S3_CFLog[CloudFront標準ログ用S3]
    DataBatch[データ投入バッチ（Lambda/週1）]
    SLI_Batch[SLI集計バッチ（Lambda/週1）]
    CW_Alarm[CloudWatchアラーム]
  end
  classDef edge fill:#fff,stroke:#333,stroke-width:2px;
  
  subgraph external["外部サービス"]
    Discord[Discordサーバ]
    Github[Githubサーバ]
  end
  
  Clients <-- 送信：HTTPリクエスト<br/>受信：静的コンテンツ/認証済みWebページ/APIレスポンス --> WAF
  Member -.-> Discord
  
  WAF <--> CF
  ACM -. 証明書提供 .-> CF
  
  CF -- Infoサイト取得 --> S3_Info
  CF -- フロントサイト（認証） --> AuthLambda
  CF -- API（認証） --> AuthLambda
  CF -- 標準ログ出力 --> S3_CFLog
  
  AuthLambda -- 認証OK --> S3_Front
  AuthLambda -- 認証OK --> API
  
  S3_Front --> API
  API --> S3_Front
  API --> S3_Backend
  
  S3_Backend ~~~ DataBatch
  DataBatch -- Discord API --> Discord
  DataBatch --> S3_Backend
  
  S3_CFLog -. 日次パーティション .-> SLI_Batch
  SLI_Batch --> S3_Backend
  
  CF -- メトリクス監視 --> CW_Alarm
  CW_Alarm -- エラー率しきい値超過時通知 --> Discord
  
  Github -- Bot運用(Github Actions) --> Discord
```

**補足:**  
- クライアント（外部ユーザ/コミュニティユーザ/スマホアプリ）は WAF → CloudFront 経由でHTTPリクエストを送信
- CloudFrontから返される全てのデータ（静的コンテンツ、認証済みWebページ、APIレスポンス）を受信
- バックエンドへの直接アクセスは行わず、全てCloudFront経由で処理
- CloudFrontのメトリクス（エラー率等）をCloudWatchアラームで監視し、しきい値超過時はDiscordに通知
- コミュニティユーザーのみDiscordサーバとの連携あり
