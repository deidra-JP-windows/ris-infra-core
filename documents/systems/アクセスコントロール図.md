```mermaid
flowchart LR
  subgraph users["ユーザー"]
    Admin[管理者]
    Member[コミュニティユーザー]
    User[外部ユーザー]
    App[スマホアプリ]
  end
  
  subgraph auth["認証・認可"]
    CloudFront[CloudFront]:::edge
    AuthLambda[トークン認証Lambda]
    RBAC[RBAC制御]
  end
  classDef edge fill:#fff,stroke:#333,stroke-width:2px;
  
  subgraph resources["リソース"]
    S3_Info[フロントinfo用S3<br/>公開リソース]
    S3_Front[フロントweb用S3<br/>認証必須]
    S3_Backend[バックエンド用S3<br/>API経由のみ]
    Lambda[バックエンドLambda<br/>認証必須]
  end
  
  User -- Web経由 --> CloudFront
  Member -- Web/アプリ経由 --> CloudFront
  App -- API経由 --> CloudFront
  Admin -- RBAC権限 --> RBAC
  
  CloudFront -- 全behavior認証 --> AuthLambda
  CloudFront -- 公開コンテンツ --> S3_Info
  
  AuthLambda -- 認証OK:静的閲覧 --> S3_Front
  AuthLambda -- 認証OK:API --> Lambda
  
  S3_Front -- APIリクエスト --> Lambda
  Lambda -- S3操作 --> S3_Backend
  
  RBAC -.-> S3_Info
  RBAC -.-> S3_Front
  RBAC -.-> S3_Backend
  RBAC -.-> Lambda
  RBAC -.-> AuthLambda
  
  S3_Info -. 静的閲覧 .-> User
  S3_Front -. 静的閲覧・API .-> Member
  S3_Backend -. データ取得/保存 .-> Lambda
```

**補足:**  
- 外部ユーザーは公開リソース（S3_Info）のみアクセス可能
- コミュニティユーザーはCloudFront経由で認証後、フロントサイトとAPIにアクセス可能
- スマホアプリはAPI経由で認証後、バックエンドリソースにアクセス
- 管理者はRBAC権限により全リソースに直接アクセス可能
- 全てのアクセスはCloudFront → トークン認証Lambda経由で制御
