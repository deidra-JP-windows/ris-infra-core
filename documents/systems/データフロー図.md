  User -- Webアクセス --> S3_Info
  Member -- Webアクセス --> S3_Front
  App -- API経由 --> BackendLambda
  
  S3_Front -- 認証リクエスト --> AuthLambda
  S3_Front <-- データ取得/保存 --> BackendLambda
  
  AuthLambda -- 認証OK --> BackendLambda
  BackendLambda -- S3操作 --> S3_Backend
  
  Discord -- Discord API --> DataBatch
  DataBatch -- データ保存 --> S3_Backend
  
  S3_CFLog -. 日次パーティション .-> SLI_Batch
  SLI_Batch -- Athena集計&Excel出力 --> S3_Backend
  
  CF_Metrics -- しきい値超過 --> CW_Alarm
  CW_Alarm -- Discord通知 --> Discord

- データソース（ユーザー、外部サービス）→ データ処理（Lambda）→ データストア（S3）の流れで構成
- 認証、API処理、バッチ処理、監視の各データフローを表現
- CloudFrontメトリクスからDiscord通知までのアラートフローも含む
